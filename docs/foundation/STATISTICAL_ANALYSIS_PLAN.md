## 1. Estimand and unit of analysis
- **N >= 1,000 (random pools):** delta_N = E[acc_FT - acc_ICL] over random size-N pools drawn without replacement from the fixed 9,003 BANKING77 training rows (BillSum: about 17,950), over training seeds and test items. It is **conditional on this training set** and labelled so in abstract and tables. A super-population claim is not made in the confirmatory family.
- **N = 200 (class-stratified pools):** conditional on the stratified draw (at least one example per class, remainder random); a separately named condition, never pooled with random cells.
- Both arms are scored on the same test items and the same pools. Analysis: paired, **crossed items x replicates** linear mixed model of d_ir = c^FT_ir - c^ICL_ir (equivalently variance components with Satterthwaite df); sensitivity: logistic GLMM with random item, replicate and item-by-arm terms. Replicate = (pool seed, training seed); ICL arms use the same pool as the FT arm of that replicate.
- Unsound and not used: majority vote over seeds then McNemar (an ensemble nobody deploys); bootstrap over 3 seeds (at most 10 distinct resamples); pooled McNemar over n*R pairs (type I error 18-45% in simulation [V by simulation]); item-mean paired t ignoring replicates (8-22%).

## 2. Type I error with overlapping pools (A4 Round 2, simulation; assumptions [U])
Nominal 5%, n=1,500, crossed model with Satterthwaite:
| Truth | N=200 | N=1,000 | N=3,000 |
|---|---|---|---|
| conditional on 9,003 rows, uncorrected, R=5/8 | 5.2-7.1% | 5.2-6.5% | 5.2-5.7% |
| super-population, uncorrected | 6.0-8.1% | 8.0-10.6% | **10.7-18.7%** |
| super-population, corrected | 5.7-7.3% | 5.6-7.0% | 6.7-8.9% |
| conditional, corrected (cost of the correction) | 4.8-6.8% | 3.4-4.7% | 1.9-3.5% |
Decision: primary = uncorrected with the conditional label; sensitivity = corrected (replace sigma^2_rep/R by sigma^2_rep(1/R + f/(1-f)), f = N/M) reported beside it. The model assumes additive pool effects on the latent scale; real pool effects may be heavier-tailed [U]. Type I error for continuous (ROUGE) scores was not simulated separately (A4-13): check at R=5 once real variance exists.

## 3. Power and minimal detectable gap (BANKING77, 3,080 items, 80% power, first-step alpha 0.0083; opt/pess regimes)
| N | R=5 cond (opt/pess) | R=8 cond (opt/pess) | R=10 |
|---|---|---|---|
| 200 | 3.8 / 7.6 | **2.7 / 5.0** | 2.5 / 4.4 |
| 1,000 | 2.6 / 4.7 | **1.9 / 3.3** | 1.9 / 2.9 |
| 3,000 | 1.8 / 2.9 | **1.6 / 2.3** | 1.6 / 2.2 |
Points of accuracy. A super-population claim needs 0.6-1.6 more. Inputs (ICL accuracy 0.70/0.80/0.87 at N=200/1,000/3,000; discordance and replicate SD from model-vs-model pilot proxies, pessimistic = 1.5x discordance, 2x replicate SD) are **unobserved for FT-vs-API** (A4-02, HIGH). The plan was to replace them by 5-replicate validation-split API runs ($7.5-11.5) before R is frozen; **that is not possible now** (no API keys and no money, L-32), so R = 8 / 5 stands on the simulation with these assumed inputs and the only data-driven step is the blinded re-estimation (section 4). In a study without the API arm the discordance would have to come from the local comparator (`PREREGISTRATION.md` s.2.1, `PC-29`). More than 3,080 test items buys nothing; R=10 buys 0.3-0.6 points at most.
**BillSum (ROUGE-L, n=1,000, R=5, alpha 0.0083):** MDG 0.6 / 1.0 / 1.9 points for replicate SD of the paired mean difference 0.2 / 0.4 / 0.8 (all [U], no data). The replicate term dominates; more bills do not help. Gaps under about 1 ROUGE-L point are not interpretable anyway (Goyal et al.: about 5-point gaps are informative).
**N=200 is the weak cell** (MDG 2.7-5.0 points): "inconclusive" is the expected outcome there. L-15 keeps it in the family; a contrast whose realised MDG exceeds the largest plausible effect is declared **underpowered a priori** and reported as a bracket, where a priori is defined numerically (06c R5, D-12): for BANKING77 the MDG from the replicate-0 validation estimates (A4-02) exceeds m = 3 points, computed once and fixed before any test read; until those estimates exist (they need API validation runs, L-32) N=200 on BANKING77 is declared a bracket by rule. **The 2-ROUGE-L-point BillSum threshold is dropped (D-12):** it is vacuous, since the MDGs 0.6 / 1.0 / 1.9 are all below 2; BillSum reports the realised interval half-width. This table does not say which N the three BillSum MDGs apply to (`PC-07`, open). MDGs re-estimated after R=5 are descriptive only. The 4-contrast family without N=200 is reported as a sensitivity analysis. (A4 objected, A4-11; the coordinator decided.)

## 4. Confirmatory family, multiplicity, decision rule
- **Six contrasts:** {BANKING77, BillSum} x N in {200, 1,000, 3,000}: best-validation fine-tuned configuration (Qwen3-4B-Instruct-2507, fixed in advance, D-05) vs best-validation in-context configuration of the best API (chosen on replicate-0 validation, frozen). Without the API arm the comparator is not decided (`PC-29`). Holm at alpha=0.05 (first-step 0.0083 in power calculations; conservative). Two-sided; both directions reported.
- **Secondary, outside the Holm family (06c R6):** FT vs kNN and API-ICL vs kNN per cell with CIs; the decision table reports the best of {kNN, API-ICL, FT} per cell with its cost, and if kNN is within m of FT the headline says so.
- Everything else is exploratory (estimates with CIs; any p-value labelled unadjusted): N=77/100, models, techniques, LEDGAR, per-class, random-vs-stratified, contamination strata.
- For each contrast report delta-hat, Holm-adjusted p, the 95% crossed-model CI and the 99.2% CI. Margin m = 3 points accuracy (BANKING77), justified as smaller than the gap at which the cost ranking could change [R]. **BillSum has no equivalence outcome** (a 1-point margin needs a CI half-width under 1 point, unreachable at the likely replicate SD; Goyal et al. treat about 5-point gaps as informative): BillSum contrasts are (i) better/worse or (iii) inconclusive only. Outcomes: (i) FT better / ICL better iff Holm p < 0.05; (ii) practically equal (descriptive) iff the 95% CI lies inside (-m, m), no equivalence p-value; (iii) **inconclusive** otherwise. The words "no difference", "equivalent", "ties" are not used for (iii). **Precedence (D-11):** the Holm-adjusted test decides; the descriptive flags never override it; a Holm-significant contrast with a gap below m is reported as "(i), gap below m"; unadjusted intervals are reported beside, labelled as such.
- Replicates: BANKING77 R=8, BillSum R=5, no confirmatory cell below 5; replicate-major; after R=5, **blinded** variance-component re-estimation (not the effect), done by a script that reads the paired difference matrix and returns only variance components and implied power, never the mean difference or its sign (D-09; the script does not exist yet); extend to at most 10 only if power for 3 points is below 80% at N=1,000 or N=3,000, N=200 excluded from the trigger (D-10; **BANKING77 only**; BillSum is capped at R=5 with its stated MDG, because +5 replicates cost 12.5-33 GPU-h). A failed replicate is retried twice, then replaced by the next unused replicate number (D-15, `PC-40`). A stochastic API arm enters the model as the item-level mean of its two full runs, scores 0 / 0.5 / 1 (D-17). The CI is conditional on the frozen arms; provider selection uncertainty is outside it (L-18). Pre-registration text must copy this section.
- No TOST in the family. rsLoRA/DoRA technique comparisons are estimation only (lr-tuned per technique; the pilot's rsLoRA gain is confounded with lr).

## 5. Metrics, intervals, learning curves
- **Classification:** accuracy over all items, unparseable = wrong; report unparseable rate, invalid-label rate, accuracy among parseable (diagnostic); macro-F1 over the full fixed label set (outputs outside it count as misses); per-class results descriptive only (about 40 items per BANKING77 class; Wilson interval about +-13 points). Calibration only where logprobs exist (ECE 15 bins plus adaptive variant, Brier); no confidence means no calibration claim.
- **Intervals:** primary = crossed-model t interval. Per-arm descriptive: two-stage percentile bootstrap (replicates then items), 10,000 resamples, fixed seed; with R<8 report replicate range plus item bootstrap and say so.
- **Crossover:** primary statement is the **bracket** from the confirmatory contrasts ("ICL better at N_j, FT not worse at N_{j+1}"); secondary N* = root of piecewise-linear delta(log N) with Monte Carlo draws from a multivariate-t using the crossed-model covariance (report P(no sign change)); parametric power-law only as sensitivity (saturated with 3-4 points). Optional exploratory N=500 and 2,000 where the bracket spans a factor of 5. Grid steps are x5 and x3, so no sharper-than-grid claim.

## 6. Summarisation evaluation (L-10)
Evidence read by A4 [V unless noted]: ROUGE/BERTScore are unreliable for small gains (Goyal et al. 2209.12356 SS1; Bhandari et al. 2010.07100); SQuALITY 2205.11465 [U, search summary]; BERTScore with `microsoft/deberta-xlarge-mnli`, rescaled, hash reported (1904.09675); SummaC (2111.09525, news benchmarks), AlignScore (2305.16739, chunked, long text), QAFactEval (2112.08542) have **no validation on long legislative text** (A4-05); LLM judges have position/verbosity/self-enhancement bias (Zheng et al. 2306.05685); LongEval (2301.13298): most surveyed papers annotate under 50 summaries, few report agreement; whether venues require human evaluation is unverified.
- **Metric set:** ROUGE-1/2/L F1 (pinned `rouge-score`, stemming, rougeLsum), BERTScore F1 rescaled; length covariates (words, compression) with every score; results also stratified by near-duplicate bin and length-matched; AlignScore and SummaC-ZS exploratory until validated; LLM judge exploratory with drop rule (Krippendorff alpha < 0.6 vs human consensus means not reported).
- **Human study (replaces the 400-rating plan):** 60 bills x 3 systems = 180 summaries (best FT, best API, a third arm), stratified by input-length tercile and near-duplicate bin, blind and shuffled; claim-level faithfulness (LongEval-style) plus 1-5 acceptability; rater 1 (author) scores all 180, rater 2 a random 90; Krippendorff alpha with bill-level bootstrap CI. Effort [assumption]: 25-40 h and 12-20 h; paid rater $180-400 at $15-20/h. Precision: metric-human Spearman rho=0.5 has CI about +-0.11-0.2; paired faithfulness-rate difference (30% discordance, n=60) about +-14 points. With it: a metric is reported as secondary evidence only if rho >= 0.5 with lower bound >= 0.3. Without it: every BillSum statement is "on ROUGE-L/BERTScore, exploratory", no faithfulness or "as good as" claim, no cost per successful summary (report cost per 1,000 outputs beside ROUGE-L). **Default (D-13): the study is not done unless the researcher names an annotator (HD-2)**, so the "without" branch applies. No ROUGE-L evaluation code exists yet (`PREREGISTRATION.md` s.16.4).

## 7. Cost statistics and break-even
- API cost per query from billed input (uncached, cached) and output tokens including reasoning, whole prompt incl. retrieved shots, retries billed, price date recorded. Self-hosted: C_train = all tuning trials + finals GPU-hours x rate; inference per query from measured GPU-s / utilisation u in {1, 0.5, 0.2}; rate band **$3.6-6.0/h** (A5; $2.3/h is a spot price, sensitivity row only; no NVL price exists [V, A5]).
- Cost per correct = (C_train + sum c_q) / sum correct_q at stated volume Q in 10^3..10^7. Q* (marginal) = C_train / (c_API - c_FT/u), valid only if c_API > c_FT/u; per-correct form Q* = C_train / (a_FT * c_API/a_API - c_FT/u). If the denominator's CI contains 0, use a **Fieller interval** or report P(denominator <= 0) and "no break-even in range"; never a percentile CI of an unbounded ratio. Resample items as (cost, correct) pairs for ratios of means, replicates for C_train and accuracy; add fixed costs after resampling (needs a new function, A4-04).
- **Labelling axis:** total = N*c_L + C_train(N) + Q*c_q; c_L cancels at fixed N and enters when arms need different N (Q*(N1 vs N2) = [C_train(N1) + (N1 - N2) c_L] / (c_API - c_FT/u)); c_L band 0.10 / 0.50 / 2.00 USD [U]. N=1,000 labels cost $100-2,000, 14-1,400x the GPU training cost, so the labelling term dominates unless the pool already exists; for BillSum the labels are sunk (CRS), so that axis is hypothetical.
- **Without the API arm (L-32, variant B of `PREREGISTRATION.md` s.2.1):** Q* against an API price can only be a projection from list prices and token counts with an assumed accuracy; the premise "FT not worse than API-ICL by more than m" cannot be checked, so such a figure is exploratory and labelled as an inputs-based projection. Cost per correct for the local arms (GPU-hours, imputed $3.6-6.0/h) stays computable.
- **Break-even sensitivity (BANKING77, k=32 request $0.000126-0.000169 sync, N=1,000 training 0.4-1.15 GPU-h incl. 4 lr trials; D-06 now gives 5 lr trials, about +25% tuning GPU, not re-derived) [I, not a result]:** items to break even, best / central / worst: API sync u=1: 9.7k / 40k / 265k; u=0.5: 11k / 91k / never; u=0.2: 21k / never / never; API batch u=1: 22k / 182k / never; batch u=0.5: 32k / never / never; u=0.2: never. Reading: a break-even exists only if the GPU stays busy and the API is called synchronously; otherwise fine-tuning's case rests on accuracy, latency or privacy, not marginal price.

## 8. What the design can and cannot support
**Can:** a paired delta with valid conditional CI per confirmatory cell (gaps above the MDGs in section 3); a bracket of the crossover; cost per correct and break-even as functions of price date and GPU band; a descriptive ROUGE/BERTScore picture plus metric validation if the human study runs. **Cannot:** 1-2 point differences at N=200/1,000; equivalence at +-1 point; a point estimate of N* sharper than the grid; any "FT >= API" quality claim for summarisation on ROUGE alone; population claims about small models or APIs (2 models, 3 APIs, one GPU type); per-class conclusions; confirmatory use of the pilot.
