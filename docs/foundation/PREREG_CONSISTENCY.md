# Pre-registration consistency check

Written 2026-11-22 while rewriting `docs/PREREGISTRATION.md`. Scope: every inconsistency, ambiguity or gap between the foundation documents (and the pilot files) on which a pre-registration has to commit to one reading. `PC-nn` ids are cited from the pre-registration. Abbreviations: `PROT` = `EXPERIMENT_PROTOCOL.md`, `STAT` = `STATISTICAL_ANALYSIS_PLAN.md`, `FEAS` = `FEASIBILITY_AND_BUDGET.md`, `DATA` = `DATASET_AUDIT.md`, `FOUND` = `RESEARCH_FOUNDATION.md`, `HD` = `HUMAN_DECISIONS.md`, `06c` = `agents/06c-independent-redteam.md`. Nothing here was run; items marked "arithmetic" were recomputed from numbers in the files. This file reports, it does not edit the other documents.

"Decide?" = the researcher must decide before the protocol tag (Y), or the recommendation can be adopted by default and only needs a nod (N).
