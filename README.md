# Label budget vs token budget

PhD Paper 1 (Istanbul Aydın University, Computer Engineering).

**Question.** When does fine-tuning a small open-weight model beat in-context learning with a cheap commercial API, given the same pool of labelled examples? And does fine-tuning add knowledge, or only redirect what the model already has?

This repository is a new study. It reuses no data from the author's MSc thesis repository ([slm-benchmark](https://github.com/Yusifnuri/slm-benchmark), frozen at tag `msc-thesis`). Some evaluation code will be ported from it.
